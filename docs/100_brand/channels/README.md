# Channels

A Channel is a distribution destination, not a Publication. Current channels are X, Instagram, LinkedIn, and YouTube; a newsletter is a future channel.

| Channel | Role |
| --- | --- |
| X | Build-journal fragments, shipping notes, and micro-observations. |
| Instagram | Reels and carousels; primarily Offline territory while carrying relevant build observation. |
| LinkedIn | Presence initially; later case studies and technical operator material. |
| YouTube | The hero cinematic vlog when launch readiness criteria are met. |

Each Publication belongs to one Channel in v1. Platform-specific roles, cadence, and readiness rules are maintained in [Marketing / Content](../marketing/content/README.md).
