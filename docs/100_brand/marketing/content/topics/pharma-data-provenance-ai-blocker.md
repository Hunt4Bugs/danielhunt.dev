# Data provenance is pharma's real AI blocker

## Premise

In pharma, the thing that actually stalls an AI initiative usually isn't the model — it's whether anyone can trace where the data feeding it came from. Daniel walked into this exact wall refactoring data models and pipelines inside a pharma R&D context before Datavial existed: the data was fragmented and poorly structured long before anyone was asking it to power a model.

## Strategic fit

Concrete evidence for the product-level contrarian ("GxP does not have to feel like GxP") and the brand-level contrarian (life sciences is underleveraged because the real gate is data discipline, not domain genius). Sits inside the Build half's 80% Life-Sciences weighting.
