# Internal workflows

1. Orient: read root and nearest `AGENTS.md`, resolve the subject in the library map, and load only relevant canonical sources.
2. Classify: select one primary class and collection; use facets and related links for all other relevance.
3. Work: distinguish evidence, interpretation, assumptions, recommendations, and decisions; keep mutable state in metadata.
4. Verify: apply `VALIDATION.md`, update the tracker or triage queue when state changes, and record the smallest durable learning.

Use `TEMPLATES.md` for new records. Treat `docs/10_brand/IDENTITY.md` and `docs/10_brand/VISUAL.md` as prerequisites for public visual or voice changes, and `docs/20_site/ARCHITECTURE.md` as the site-implementation reference.
