# Creator records

You are in the instance directory for `content.creator`. Store content-producing entities —
people, companies, brands, or organizations — being monitored for competitor, inspiration, peer,
or reference intelligence here.

- What a Creator *is* (definition, relationships, constraints, entity contract):
  [`concepts.md`](../concepts.md#creator).
- What a Creator document must *contain* (required sections): [`_patterns/creator.md`](../_patterns/creator.md).
- Related instance directories: [Creator Channels](../creator-channels/README.md) (a Creator's
  specific platform accounts).
