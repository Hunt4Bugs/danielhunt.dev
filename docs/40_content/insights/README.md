# Insight records

Store interpretations of one or more Measurements here. Each Insight links its Measurements, states the interpretation, separates evidence from inference, records limitations and competing explanations, identifies Knowledge created or revised, and links the creating Work Item.

An Insight may recommend later work. It may not silently change Strategy, taxonomy, or the controlling editorial plan.
