# Creator Type

## Definition

What kind of entity a Creator is. Single-valued.

Creator Type answers *what is this entity?*. Creator Relationship answers *what is our stance
toward it?*. They are separate classifications and must never be conflated into one field.

## Values

| Value | Definition |
| --- | --- |
| Person | An individual human being. |
| Company | A commercial entity trading under its own name. |
| Brand | A named identity that is not itself a legal entity, often operated by a person or company. |
| Organization | A non-commercial body: an institution, a community, a public project. |
| Other | An entity worth recording that none of the above describes. |
