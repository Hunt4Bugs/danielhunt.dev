# Workflow Stage

## Definition

Where a particular execution sits in the content lifecycle. The lifecycle is not a strict
one-to-one pipeline: Knowledge and Topics are reusable, one Topic may produce several Blueprints,
and a repurposed expression is a separate Publication.

## Values

| Value | Definition |
| --- | --- |
| Capture | Raw material is being taken in and attributed. |
| Validate | Evidence and premise are being checked. |
| Plan | The subject is being developed into something communicable. |
| Draft | An expression is being written. |
| Review | A draft is being checked against brand rules and its own promise. |
| Produce | Assets are being made. |
| Publish | The expression is going out on a channel. |
| Measure | Results are being collected. |
| Learn | Results are being turned into Insight. |
| Reuse / Repurpose | An existing expression is being adapted for another channel or format. |
