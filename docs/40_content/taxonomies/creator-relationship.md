# Creator Relationship

## Definition

Our stance toward a Creator. Multi-valued — a Creator may hold more than one simultaneously, for
example both Competitor and Inspiration. `Self` marks Daniel Hunt's own record.

## Values

| Value | Definition |
| --- | --- |
| Competitor | A Creator working the same subject area and audience, tracked for positioning. |
| Inspiration | A Creator whose craft or approach is worth studying, without competing directly. |
| Peer | A Creator at comparable stage or standing, where exchange is mutual. |
| Reference | A Creator cited as evidence or example rather than tracked continuously. |
| Self | Daniel Hunt's own record. Exactly one Creator carries this value. |
