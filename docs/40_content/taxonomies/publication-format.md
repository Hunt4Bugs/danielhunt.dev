# Publication Format

## Definition

The channel-neutral form of a Publication. The Channel identifies where a Publication appears;
the Format identifies what shape it takes there.

## Values

| Value | Definition |
| --- | --- |
| Text Post | A short written post, published inline on its channel. |
| Thread | A sequence of linked short posts read in order. |
| Carousel | An ordered set of image or slide panels. |
| Short-form Video | Vertical video, typically under a minute. |
| Long-form Video | Horizontal video with a developed structure. |
| Article | A long-form written piece with its own title and structure. |
| Newsletter | A written issue delivered to subscribers. |
