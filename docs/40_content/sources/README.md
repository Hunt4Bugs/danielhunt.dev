# Source records

You are in the instance directory for `content.source`. Store provenance records here for
external and firsthand material that supports Knowledge. A Source is not automatically an
approved brand claim.

- What a Source *is* (definition, relationships, constraints, entity contract):
  [`concepts.md`](../concepts.md#source).
- What a Source document must *contain* (required sections): [`_patterns/source.md`](../_patterns/source.md).
- What *creates* a Source: the [Capture Knowledge](../workflows/capture-knowledge.md) workflow.
- Related instance directories: [Knowledge](../knowledge/README.md) (supported by a Source).
