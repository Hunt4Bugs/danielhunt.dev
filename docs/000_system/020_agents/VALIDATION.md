# Validation

For each internal artifact, confirm one primary class, a mapped collection, valid metadata, resolved relative links, sources for material claims, and clearly labeled unknowns. For site changes, also inspect the static HTML/CSS/JS relevant to the change and run the smallest available local check. There is no configured test suite or build step as of this record.
