# Autonomy boundaries

Agents may read repository evidence, classify internal artifacts, update local documentation, and run reversible validation. They may not publish content, deploy, alter GitHub settings or secrets, install plugins, change global configuration, create external tickets, send messages, or make legal, financial, or customer commitments without explicit approval.

When evidence conflicts, preserve the conflict in a record and favor the more recent source only when its scope clearly supersedes the older one. If the next action would affect a public surface or external system, stop at a recommendation.
