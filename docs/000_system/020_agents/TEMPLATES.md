# Record template

```yaml
---
class: "000"
collection: records
type: decision | audit | setup | note
status: draft
owner: Daniel Hunt
created: YYYY-MM-DD
updated: YYYY-MM-DD
facets: []
related: []
sources: []
---
```

Follow with `Evidence`, `Interpretation`, `Assumptions`, `Decision or recommendation`, `Risks and open questions`, `Next actions`, and `Learning update`. Omit empty sections only when they are genuinely inapplicable.
