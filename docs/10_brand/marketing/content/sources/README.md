# Source records

Store provenance records here for external and firsthand material that supports Knowledge. A Source is not automatically an approved brand claim.

Each Source records title, origin or provider, source format, date or timeframe when known, access conditions, scope, verification limits, and the Work Item that created it. Preserve the distinction between accessible source material, attributed firsthand context, and an unsupported assertion.
